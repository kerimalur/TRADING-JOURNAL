Python Integration

Beispiel-Code zum Laden der exportierten Daten in Python: 

import json
import pandas as pd

# JSON-Datei laden
with open('trading_ml_data_2025-12-13.json', 'r') as f:
    data = json.load(f)

# COT Daten als DataFrame
cot_df = pd.DataFrame([
    {'date': d, 'currency': c, **v}
    for c, entries in data['cot_data'].items()
    for d, v in [(e['date'], e) for e in entries]
])

# News Daten als DataFrame
news_df = pd.DataFrame([
    {'date': d, 'currency': c, **v}
    for c, entries in data['news_data'].items()
    for d, v in [(e['date'], e) for e in entries]
])

# ML Features (Zeitreihen)
features_df = pd.DataFrame(data['features'])

# Trades als Labels
trades_df = pd.DataFrame(data['trades'])

print(f"COT Einträge: {len(cot_df)}")
print(f"News Einträge: {len(news_df)}")
print(f"Features: {len(features_df)}")
print(f"Trades: {len(trades_df)}")

Generierte ML-Features

Diese Features werden automatisch aus den Rohdaten generiert und können direkt für ML-Modelle verwendet werden:

[CURRENCY]_cot_net Commercial Net Position für jede Währung
[CURRENCY]_cot_change Wöchentliche Änderung der Position
[CURRENCY]_news_sentiment Durchschnittliches News-Sentiment (-2 bis +2)
[CURRENCY]_news_count Anzahl der News-Events pro Tag
Tipp: Kombiniere diese Features mit technischen Indikatoren für bessere Vorhersagen. Die COT-Daten sind besonders nützlich für Swing-Trading über mehrere Tage.
