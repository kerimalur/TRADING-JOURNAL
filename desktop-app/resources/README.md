# Resources Folder

Dieses Verzeichnis enthält Ressourcen für die Desktop-Anwendung.

## Icon erstellen

Für das App-Icon benötigst du eine `icon.ico` Datei.

### So erstellst du ein Icon:

1. Erstelle ein PNG-Bild (mindestens 256x256 Pixel)
2. Konvertiere es zu ICO mit einem Online-Tool wie:
   - https://convertio.co/png-ico/
   - https://icoconvert.com/
3. Speichere die Datei als `icon.ico` in diesem Ordner

### Empfohlene Größen im ICO:
- 16x16
- 32x32
- 48x48
- 64x64
- 128x128
- 256x256

## Temporäre Lösung

Falls du noch kein Icon hast, wird der Build trotzdem funktionieren, aber das Standard-Electron-Icon verwendet.
